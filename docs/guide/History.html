Era 系列历史

前言

了解一点历史，能帮我们理解“为什么脚本长这样”。Era 系列走过了一段不短的岁月，才形成今天的样子。这一节只是简略的脉络梳理，不求详尽，但求让你心里有张地图。

Eramaker：最早的引擎

Era 系列游戏的起点，是日本的 Eramaker 引擎。

它提供了一套用 CSV 描述数据、用 ERB 编写剧情的开发方式，让没有编程基础的人也能做出有数值、有剧情、可反复游玩的文字游戏。今天我们写脚本时用到的大量概念——函数、变量、PRINT 命令、内置流程——都能追溯到它。

不过，Eramaker 在功能、性能和兼容性上都有不少局限，后来渐渐停止了维护。

Emuera：兼容并扩展的后继者

为了在保持兼容的前提下解决 Eramaker 的问题，社区出现了以 Emuera 为代表的新引擎。

Emuera 用 C# 重写，基本完整地兼容了 Eramaker 的 CSV 与 ERB，同时对许多“不自然的行为”做了修正（比如数组越界、RAND 的取值范围等）。更重要的是，它扩展了大量新语法：

  • #DIM / #DIMS 等用户自定义变量；
  • IF / REPEAT / FOR / SELECTCASE 等更丰富的复合语句；
  • 三元运算、字符串拼接、正则表达式等表达式能力；
  • 用户自定义函数、头文件、宏……

我们这套教程里讲的大部分内容，其实都是 Emuera 的语法。想看清 Emuera 与 Eramaker 到底有哪些不同，可以专门阅读与 Eramaker 的差异。

改造版与社区

Emuera 本身也在社区中衍生出许多改造版（比如各种“私家版”、EM+EE 等），它们在 Emuera 的基础上又添加了图片、动画、工具提示、更多内置函数等功能。

这对开发者的意义是：同一个脚本，在不同改造版里的表现可能不同。写游戏时，最好先弄清楚目标玩家用的是哪一款引擎，再决定能用哪些特性。

EraBasic：我们写的语言

不管是 Eramaker 还是 Emuera，我们写的脚本语言都叫 EraBasic。

它是一门为“文字 + 数值”游戏量身定做的脚本语言：没有类的概念，没有复杂的内存管理，但非常适合快速地把玩法原型写出来。它的设计目标从来不是“强大”，而是“让创作者能立刻上手”。

这个项目

本中文文档项目（ECD）的目标，是把 Eramaker 与 Emuera 的官方文档完整地翻译过来，并补充面向中文使用者的原创教程与参考。

  • 想从零开始：请回到快速开始；
  • 想系统学习：请进入入门教程；
  • 想查阅命令与变量：请移步参考区域。
