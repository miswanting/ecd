Config 文件参考 ​

emuera.config 是 Emuera 的配置文件，首次运行时会自动在游戏根目录生成。它记录了窗口、字体、存档、调试等各方面的设置。

  • 文件为纯文本，每行形如 配置项:值；
  • 配置项名称是日文原文，请保持原样，不要翻译；
  • 大部分设置也可以在游戏内的设置对话框中修改；
  • 也可以在 CSV/ 中放置 _default.config、_fixed.config 来批量覆盖，详见强制配置项目。

下面按用途分类列出常用配置项。

ユーザー関数の引数に自動的にTOSTRを補完する是否自动为用户函数参数补上 TOSTRNO
FORM中の三連記号を展開しない是否禁止展开 FORM 中的三连符号NO
TIMESの計算をeramakerにあわせるTIMES 的计算是否与 Eramaker 一致NO
キャラクタ変数の引数を補完しない是否不补全角色变量的参数NO
