# 错误索引表

本页汇总 Emuera 常见的错误与警告信息，按“运行错误”“代码错误”“警告”分类，方便你在看到报错时快速定位。排错方法的教程版见[错误与异常](../guide/tutorials/Error)。

> 报错时，除了画面上的信息，根目录下的 `emuera.log` 里还有更详细的记录（文件名、行号、函数名等）。

## 运行错误

在游戏运行过程中出现。

| 错误信息（原文） | 含义 | 常见原因与对策 |
| --- | --- | --- |
| `関数"@XXX"が見つかりません` | 找不到函数 `@XXX` | 函数名拼错、忘了定义，或定义在未被读取的文件里 |
| `予期しないスクリプト終端です` | 预料之外的脚本结尾 | 函数或复合语句没有写完，检查出错位置附近 |
| `配列の範囲外です` | 访问了数组范围之外的位置 | 数组从 0 开始；检查下标是否越界或为负 |
| `...はキャラ登録番号の範囲外です` | 角色编号超出范围 | 检查 `ADDCHARA` / 角色变量使用的编号 |
| `代入文の左辺に変更できない変数を指定することはできません` | 不能给不可修改的变量赋值 | 不要给常量、伪变量或只读变量赋值 |
| `'='の前後で型が一致しません` | 赋值号两边类型不同 | 字符串变量要用 `#DIMS` 定义，值要加引号 |
| `ASSERT文の引数が0です` | `ASSERT` 断言失败 | 前提条件不成立；检查触发该断言的数据 |
| `...は数値として解釈できません` | 无法作为数值解释 | 检查该处是否应当传入字符串 |
| `...が64ビット符号付き整数の範囲外です` | 数值超出 64 位整数范围 | 检查计算是否溢出，或输入的数值过大 |

## 代码错误

在加载脚本、解析语法时出现。

| 错误信息（原文） | 含义 | 常见原因与对策 |
| --- | --- | --- |
| `IFに対応するENDIFが設定されていない` | 缺少与 `IF` 配对的 `ENDIF` | 补齐 `ENDIF`；用编辑器的折叠功能检查嵌套 |
| `...に対応する...が見つかりません` | 括号/引号没有闭合 | 检查 `()`、`[]`、`{}`、`""`、`%%` 是否成对 |
| `SIF文の次の行がありません` | `SIF` 后面没有下一行 | 在 `SIF` 下一行写上要执行的语句 |
| `SIF文の次の行をラベル行にすることはできません` | `SIF` 的下一行是标签 | 调整代码顺序，不要用标签紧跟在 `SIF` 后面 |
| `$で始まるラベルに引数が設定されています` | 标签后面写了参数 | 标签不能带参数，删除多写的部分 |
| `REPEAT文が入れ子にされています（無限ループの恐れがあります）` | `REPEAT` 嵌套异常 | 检查 `REPEAT` / `REND` 是否配对，避免误嵌套 |
| `4次元以上の配列変数を宣言することはできません` | 数组维度超过上限 | 最多 3 维，重新设计数据结构 |
| `CONSTキーワードが指定された変数を多次元配列にはできません` | 常量不能是多维数组 | 把常量改为一维数组 |
| `ARRAYCOPY命令の2つの配列変数の型が一致していません` | `ARRAYCOPY` 的类型不同 | 让源数组与目标数组的类型、维度一致 |
| `CASEの引数の型がSELECTCASEと一致しません` | `CASE` 与 `SELECTCASE` 类型不同 | 保持两者同为数值或同为字符串 |
| `GETBIT関数の第2引数(...)が範囲(0～63)を超えています` | 位位置超出范围 | `GETBIT` 的位位置必须在 0～63 |
| `CBRT関数の引数に負の値が指定されました` | 对负数求立方根相关错误 | 检查参数是否应为非负 |
| `ENCODETOUNIの引数が長すぎます` | `ENCODETOUNI` 的字符串过长 | 缩短要编码的字符串 |

## 警告

警告不会中断运行，但往往预示着潜在问题。

| 警告信息（原文） | 含义 | 建议 |
| --- | --- | --- |
| `SIF文の次の行が空行またはコメント行です(eramaker:SIF文は意味を失います)` | `SIF` 的下一行是空行/注释 | 删掉 `SIF` 与目标行之间的空行、注释 |
| `#FUNCTIONが定義されていない関数(...)` | 用了 `#FUNCTION` 却没有对应定义 | 检查属性与函数定义是否匹配 |
| `#FUNCTIONSで始まる関数の戻り値に数値型が指定されました` | `#FUNCTIONS` 函数返回了数值 | 字符串函数应返回字符串 |
| `#ONLYが指定されたイベント関数では#PRIは機能しません` | `#ONLY` 会使 `#PRI` 失效 | 不要同时使用这两个属性 |
| `#ONLYが指定されたイベント関数では#LATERは機能しません` | `#ONLY` 会使 `#LATER` 失效 | 同上 |
| `#ONLYが指定されたイベント関数では#SINGLEは機能しません` | `#ONLY` 会使 `#SINGLE` 失效 | 同上 |
| `#PRIと#LATERが重複して使われています(この関数は2度呼ばれます)` | 同时指定 `#PRI` 与 `#LATER` | 该函数会被调用两次，确认是否本意 |
| `この関数にはすでに#LOCALSIZEが定義されています。（以前の定義は無視されます）` | 重复定义 `#LOCALSIZE` | 每个函数只保留一处定义 |
| `同名の非イベント関数が複数定義されたとき警告する` | 同名非事件函数被重复定义 | 重命名或合并函数 |
