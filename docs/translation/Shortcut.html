快捷键 ​

翻译自原文档：https://osdn.net/projects/emuera/wiki/shortcut

在 Emuera 中，可以用快捷键完成一些操作。

快捷键作用
Ctrl + B最小化 Emuera 窗口
Ctrl + C、Ctrl + Insert打开剪贴板对话框。仅在没有选中任何字符时有效；选中了字符时则只是复制该字符
Ctrl + V、Shift + Insert粘贴已复制的字符
Ctrl + D打开调试窗口。仅在以调试模式启动时有效
Ctrl + R更新调试窗口中的信息，焦点不会移动。仅在以调试模式启动时有效
Ctrl + 0～9把宏分组切换为分组 0～9
Shift + F1～F12把当前输入的字符串作为宏分配到 F1～F12
F1～F12调用分配到对应键的宏
Esc宏执行中按下，可中断宏

关于宏的用法，请参阅使用指南中的宏一节。
