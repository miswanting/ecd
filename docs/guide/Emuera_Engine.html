Emuera 引擎的使用 ​

前言 ​

在正式写游戏之前，我们先把“舞台”认识清楚：Emuera 是什么？它有几种启动方式？一个游戏文件夹里都有些什么？这一节不写代码，但会让你后面的每一步都更踏实。

教程依赖

本教程假设您已学习过快速开始。若您尚未学习过，我们强烈推荐您首先学习相应教程。

Emuera 是什么 ​

Emuera 是一个用于运行 Era 系列游戏的引擎。它兼容更早期的 Eramaker 脚本，同时扩展了大量新语法。我们写的 ERB 脚本，最终就是交给它来执行的。

  • 引擎本体：一个 EmueraXXXX.exe 文件；
  • 游戏内容：CSV/ 里的数据文件，加上 ERB/ 里的脚本；
  • 配置：根目录下自动生成的 emuera.config。

三种启动模式 ​

Emuera 有两种常用的启动方式，区别在于“怎么启动它”。

普通模式 ​

直接双击 EmueraXXXX.exe，就是普通模式。这是我们玩游戏、也是测试游戏时的默认模式。

解析模式 ​

把 ERB 文件或文件夹拖到 EmueraXXXX.exe 上，就会进入解析模式。它会检查被拖入文件有没有语法错误，非常适合在写代码时快速自检——不用真的把游戏跑起来，就能发现拼写、配对之类的低级错误。

调试模式 ​

以命令行参数 -debug 启动 Emuera，就进入调试模式。调试模式能查看变量、逐行执行，是排错时的利器。详情可以参考调试模式。

一个游戏文件夹里有什么 ​

一个最精简的游戏文件夹（我们用 root 来代表）结构如下：

root/
 ├─ emuera.config      ← 引擎配置（首次运行时自动生成）
 ├─ Emuera1824.exe     ← 引擎本体
 ├─ CSV/               ← 数据文件
 └─ ERB/               ← 脚本文件
     └─ System.erb     ← 我们写的脚本

随着游戏变复杂，还会多出这些：

文件夹/文件用途
resources/图片等资源
sav/存档、全局数据等
emuera.log运行日志，报错时来这里找线索

配置对话框 ​

在游戏窗口的菜单里可以打开设置对话框，里面能调整字体、颜色、是否显示存档列表等选项。大部分选项保持默认就好，等真正需要时再来调整。

想了解每一项的含义，可以查阅参考-配置文件以及术语表。

小结 ​

  • Emuera 是运行 Era 系列游戏的引擎；
  • 双击是普通模式，拖入文件是解析模式，加 -debug 是调试模式；
  • 一个游戏 = CSV/ + ERB/ + emuera.config；
  • 报错时，记得去根目录看 emuera.log。
