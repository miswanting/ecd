错误索引表

本页汇总 Emuera 常见的错误与警告信息。前几节是按含义整理的常见问题；页面末尾还嵌入了从引擎源码提取的完整错误信息索引，可以按日文原文搜索。

报错时，除了画面上的信息，根目录下的 emuera.log 里还有更详细的记录（文件名、行号、函数名等）。排错方法的教程版见错误与异常。
