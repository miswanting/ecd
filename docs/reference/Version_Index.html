版本特性索引

Emuera 的版本号形如 1.XXX，开发版可能带字母（如 1.756alpha018）。本页汇总文档中提到的、与具体版本相关的功能与行为变化，便于快速判断“我的版本支持这个特性吗 / 这个行为是什么时候变的”。

官方完整的更新履历（history）尚未包含在本仓库中，欢迎贡献翻译。本页只收录文档正文里出现过的版本信息。

一览

版本变化 / 新增出处
1.700新增 WINAPI 绘制接口（用 TextOut 绘制）配置项详解
1.704SAVEDATA 的第 2 参数可以直接使用字符串表达式命令
1.705商店可购买的物品范围不再能改变程序流程
1.712新增表达式内函数（方法）；STRFIND 可指定第 3 参数（查找起始位置）表达式内函数、命令
1.721函数名含符号从“立即报错”改为警告 Lv 1与 Eramaker 的差异
1.736PRINT 系的关键字 K 与 D 不能同时指定命令
1.739DRAWLINE 等换行规格发生变化（可用兼容开关重现旧行为）配置项详解
1.750新增调试模式调试模式
1.751b → 1.752#SINGLE 的中断条件修正为“返回值仅为 1 时”与 Eramaker 的差异
1.800事件函数的 #PRI / #LATER / #SINGLE 调用顺序完全重现 Eramaker与 Eramaker 的差异
1.800ロード時にFORM文字列を解析する 选项被废除配置项详解
1.803 → 1.805GAMEBASE_GAMECODE 的数值范围与存档读取规则变化与 Eramaker 的差异
1.806DRAWLINEを常に新しい行で行う 选项被废除配置项详解
1.807 → 1.808函数参数类型不再自动转换；参数省略规则变化配置项详解
1.808SKIPDISP 可以紧跟在 SIF 之后；SKIPDISP 会把 RESULT:0 重置为 0命令
1.810支持参数引用传递（形参用引用型变量）函数与预处理指令
1.813支持用字符串表达式给字符串变量赋值（'=）常规
1.815REF 指令不再可用用户自定义变量
1.816不再默认支持 SP 角色（CFLAG:0 不再特殊）命令
1.818イメージバッファを使用する 选项被废除配置项详解
1.820ユーザー関数の引数に自動的にTOSTRを補完する 的效果曾一度反转配置项详解
1.823资源文件可以放在 resources/ 的子文件夹中资源
1.824已有 GSETFONT / GSETPEN 设置，但尚无使用它们的指令命令
1738g解析模式下启用加载时显示报告可显示加载报告术语表
1800对事件函数使用 #LOCALSIZE 时，采用最先执行的函数的设置函数与预处理指令
1807符合“角色多维数组变量”的只有 CDFLAG术语表
