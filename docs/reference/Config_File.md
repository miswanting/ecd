# Config 文件参考

`emuera.config` 是 Emuera 的配置文件，首次运行时会自动在游戏根目录生成。它记录了窗口、字体、存档、调试等各方面的设置。

- 文件为**纯文本**，每行形如 `配置项:值`；
- 配置项名称是**日文原文**，请保持原样，不要翻译；
- 大部分设置也可以在游戏内的设置对话框中修改；
- 也可以在 `CSV/` 中放置 `_default.config`、`_fixed.config` 来批量覆盖，详见[强制配置项目](../translation/Config)。

下面按用途分类列出常用配置项。

## 基础

| 配置项 | 含义 | 默认值 |
| --- | --- | --- |
| `大文字小文字の違いを無視する` | 是否忽略命令/变量的大小写 | `YES` |
| `全角スペースをホワイトスペースに含める` | 是否把全角空格也当作空白 | `YES` |
| `関数・属性については大文字小文字を無視しない` | 函数、属性名是否区分大小写 | `NO` |
| `内部で使用する東アジア言語` | 内部使用的东亚语言 | `JAPANESE` |
| `解釈不可能な行があっても実行する` | 遇到无法解释的行是否仍然继续执行 | `NO` |

## 文件与目录

| 配置项 | 含义 | 默认值 |
| --- | --- | --- |
| `_Rename.csvを利用する` | 是否使用 `_Rename.csv` | `NO` |
| `_Replace.csvを利用する` | 是否使用 `_Replace.csv` | `YES` |
| `サブディレクトリを検索する` | 是否搜索子目录中的脚本 | `NO` |
| `読み込み順をファイル名順にソートする` | 是否按文件名排序读取 | `NO` |
| `関連づけるテキストエディタ` | 关联的文本编辑器 | `notepad` |
| `テキストエディタコマンドライン指定` | 编辑器命令行参数 | `USER_SETTING` |
| `エディタに渡す行指定引数` | 传递给编辑器的行号参数 | （空） |

## 窗口与显示

| 配置项 | 含义 | 默认值 |
| --- | --- | --- |
| `ウィンドウ幅` | 窗口宽度 | `760` |
| `ウィンドウ高さ` | 窗口高度 | `480` |
| `ウィンドウ位置X` / `ウィンドウ位置Y` | 窗口初始坐标 | `0` |
| `起動時のウィンドウ位置を指定する` | 是否使用指定的窗口位置 | `NO` |
| `起動時にウィンドウを最大化する` | 启动时是否最大化窗口 | `NO` |
| `ウィンドウの高さを可変にする` | 窗口高度是否可调整 | `YES` |
| `描画インターフェース` | 绘制接口（`TEXTRENDERER` / `GRAPHICS` / `WINAPI`） | `TEXTRENDERER` |
| `フレーム毎秒` | 每秒重绘帧数 | `5` |
| `最大スキップフレーム数` | 最大跳帧数 | `3` |
| `スクロール行数` | 一次滚动的行数 | `1` |
| `履歴ログの行数` | 保留的历史日志行数 | `5000` |
| `PRINTCを並べる数` | 一行能并排几个 `PRINTC` | `3` |
| `PRINTCの文字数` | `PRINTC` 补齐到的字符数 | `25` |
| `ボタンの途中で行を折りかえさない` | 是否禁止在按钮中间换行 | `NO` |

## 字体与颜色

| 配置项 | 含义 | 默认值 |
| --- | --- | --- |
| `フォント名` | 字体名称 | `ＭＳ ゴシック` |
| `フォントサイズ` | 字号 | `18` |
| `一行の高さ` | 行高 | `19` |
| `文字色` | 文字颜色（R,G,B） | `192,192,192` |
| `背景色` | 背景颜色 | `0,0,0` |
| `選択中文字色` | 选中项的文字颜色 | `255,255,0` |
| `履歴文字色` | 历史记录的文字颜色 | `192,192,192` |

## 输入与操作

| 配置项 | 含义 | 默认值 |
| --- | --- | --- |
| `マウスを使用する` | 是否允许鼠标操作 | `YES` |
| `メニューを使用する` | 是否启用菜单 | `YES` |
| `キーボードマクロを使用する` | 是否启用键盘宏 | `YES` |
| `多重起動を許可する` | 是否允许同时运行多个实例 | `YES` |
| `ONEINPUT系命令でマウスによる2文字以上の入力を許可する` | `ONEINPUT` 系是否允许鼠标输入多个字符 | `NO` |

## 存档

| 配置项 | 含义 | 默认值 |
| --- | --- | --- |
| `表示するセーブデータ数` | 显示多少个存档槽 | `20` |
| `セーブデータをsavフォルダ内に作成する` | 存档是否放进 `sav/` 文件夹 | `NO` |
| `セーブデータをUTF-8で保存する` | 存档是否以 UTF-8 保存 | `NO` |
| `セーブデータをバイナリ形式で保存する` | 存档是否以二进制格式保存 | `NO` |
| `オートセーブを行なう` | 是否进行自动保存 | `YES` |
| `CALLNAMEが空文字列の時にNAMEを代入する` | 当 `CALLNAME` 为空时是否用 `NAME` 代替 | `NO` |

## 调试与警告

| 配置项 | 含义 | 默认值 |
| --- | --- | --- |
| `デバッグコマンドを使用する` | 是否启用调试命令 | `NO` |
| `ロード時にレポートを表示する` | 加载时是否显示报告 | `NO` |
| `ロード時に引数を解析する` | 加载时是否解析参数 | `NO` |
| `無限ループ警告までのミリ秒数` | 执行多少毫秒后提示无限循环警告 | `5000` |
| `表示する最低警告レベル` | 显示的最低警告等级 | `1` |
| `呼び出されなかった関数を無視する` | 是否忽略未被调用的函数 | `YES` |
| `関数が見つからない警告の扱い` | 找不到函数时警告的处理（`IGNORE` 等） | `IGNORE` |
| `関数が呼び出されなかった警告の扱い` | 函数未被调用时警告的处理 | `IGNORE` |
| `同名の非イベント関数が複数定義されたとき警告する` | 同名非事件函数重复定义时是否警告 | `NO` |
| `システム関数の上書きを許可する` | 是否允许覆盖系统函数 | `YES` |
| `システム関数が上書きされたとき警告を表示する` | 系统函数被覆盖时是否警告 | `YES` |
| `イベント関数のCALLを許可する` | 是否允许用 `CALL` 调用事件函数 | `NO` |

## 兼容性开关

这些开关用于让 Emuera 更多地“模仿”Eramaker 的旧行为。除非要运行旧脚本，否则保持默认即可。

| 配置项 | 含义 | 默认值 |
| --- | --- | --- |
| `eramaker互換性に関する警告を表示する` | 是否显示 Eramaker 兼容性警告 | `YES` |
| `擬似変数RANDの仕様をeramakerに合わせる` | `RAND` 是否按 Eramaker 的规格工作 | `NO` |
| `ver1739以前の非ボタン折り返しを再現する` | 是否复现 ver1739 之前的换行行为 | `NO` |
| `SPキャラを使用する` | 是否启用 SP 角色 | `NO` |
| `ユーザー関数の全ての引数の省略を許可する` | 是否允许省略用户函数的全部参数 | `NO` |
| `ユーザー関数の引数に自動的にTOSTRを補完する` | 是否自动为用户函数参数补上 `TOSTR` | `NO` |
| `FORM中の三連記号を展開しない` | 是否禁止展开 FORM 中的三连符号 | `NO` |
| `TIMESの計算をeramakerにあわせる` | `TIMES` 的计算是否与 Eramaker 一致 | `NO` |
| `キャラクタ変数の引数を補完しない` | 是否不补全角色变量的参数 | `NO` |
| `文字列変数の代入に文字列式を強制する` | 是否强制用字符串表达式给字符串变量赋值 | `NO` |
