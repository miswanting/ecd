ERB 文件结构 ​

ERB/ 文件夹存放游戏的脚本。Emuera 启动时会读取这里所有扩展名为 .erb 的文件，以及 .erh 头文件。

文件与编码 ​

  • 脚本文件扩展名为 .erb，头文件为 .erh；
  • 编码通常为 Shift-JIS；
  • 一行一句：除特殊行外，每一行都是一条语句；
  • 缩进（行首空格）不影响运行，但强烈建议使用，详见 MCS 代码风格。

行的种类 ​

行的开头种类说明
@函数定义定义一个函数
#预处理指令属性、变量定义、宏等
$标签供 GOTO 跳转的目标
[ … ]特殊区块如 [SKIPSTART]、[IF XXX]
;注释被忽略（;!;、;#; 例外）
其他普通语句赋值、命令调用等

函数定义 ​

erb
@函数名
  ; 函数体
  RETURN

带参数的函数：

erb
@函数名, ARG:0, ARGS:0
  ; 数值参数在 ARG，字符串参数在 ARGS
  RETURN
  • 函数从 @ 行开始，到下一个 @ 行或文件末尾结束；
  • 一个文件可以定义多个函数；
  • 事件函数（如 @EVENTFIRST）由引擎在特定时机调用，详见内置流程。

预处理指令 ​

以 # 开头的行，分为属性和定义两类：

  • 属性：描述函数的性质，如 #FUNCTION、#FUNCTIONS、#PRI、#LATER、#SINGLE、#ONLY；
  • 定义：定义变量或宏，如 #DIM、#DIMS、#DEFINE、#LOCALSIZE。

它们必须紧跟在函数定义之下。详见函数与预处理指令。

标签与跳转 ​

erb
$标签名
GOTO 标签名

GOTO 只能跳到标签（$）或函数（@），不能跳到语句中间。

注释 ​

erb
; 整行注释
A = 10  ; 行末注释

两个特殊注释行用于控制引擎行为：

  • ;!;：这一行在 Emuera 中有效，在 Eramaker 中被当作注释；
  • ;#;：这一行只在调试模式下执行。

行连接 ​

当一个表达式太长时，可以用 { } 把它拆成多行：

erb
{
  #DIM HOGE =
    1,2,3,4
}

{ 与 } 必须单独成行，且换行处会补上一个半角空格。详见常规。

文件的读取顺序 ​

Emuera 会读取 ERB/ 下的所有文件。默认顺序取决于文件系统，可能影响同名函数、相性等的结果。如果顺序很重要，可以在配置中启用読み込み順をファイル名順にソートする。
