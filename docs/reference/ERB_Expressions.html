ERB 的表达式

表达式是“能算出结果的东西”。本页汇总 EraBasic 表达式的组成元素与规则。更详细的说明请参阅运算与常规。

字面量

种类写法例子
十进制整数直接书写123、-5
十六进制整数0x 开头0xFF
二进制整数0b 开头0b1010
字符串双引号包围"Hello"
格式化字符串@"..."@"{A} 点"
文本（命令参数）不加引号PRINT Hello

数值是 64 位有符号整数，没有小数。5 / 3 的结果是 1。

运算符与优先级

从高到低：

分类优先级符号
单目运算符高~、!、-（负号）
算术运算符↑*、/、%
+、-
位移运算符<<、>>
比较运算符<、>、<=、>=、==、!=
位运算符&、`
逻辑运算符↓&&、`
三元运算符低? … #
赋值运算符最低=、+=、-=、*=、/=、%=、'=

算术

符号含义
+加法（字符串则为拼接）
-减法
*乘法（字符串 * 整数为重复）
/整除
%取余

比较与逻辑

符号含义
== / !=等于 / 不等于
< / > / <= / >=大小比较
&& / `
!逻辑非
^^ / !& / `!`

比较结果为 1（真）或 0（假）。&& 与 || 会短路求值：A && B 中若 A 为假则不再计算 B。

三元运算符

变量 = 条件 ? 为真时的值 # 为假时的值

字符串版本需要外层 \@ … \@：

变量 = \@条件 ? 为真时的文本 # 为假时的文本\@

它等价于：

IF 条件
  变量 = 为真时的值
ELSE
  变量 = 为假时的值
ENDIF

FORM 语法

在 PRINTFORM 等命令中，可以嵌入表达式，并按指定宽度对齐：

  • {数值表达式}：展开为数值；
  • {数值表达式, 宽度, LEFT/RIGHT}：按宽度对齐；
  • %字符串表达式%：展开为字符串；
  • %字符串表达式, 宽度, LEFT/RIGHT%：按宽度对齐。
PRINTFORM 金币：{MONEY}
PRINTFORM 姓名：%NAME:0%
PRINTFORM [{MONEY,10,LEFT}]

三连符号（***、$$$、+++、///、===）用于替换角色姓名等，详见 Str.csv。

式中函数

表达式里可以调用式中函数，它们像普通函数一样接收参数、返回结果：

A = ABS(X)
B = STRLEN(S)
C = RAND(100)
D = SUBSTRING(S, 1, 3)

内置式中函数的完整清单见表达式内函数。

类型与转换

  • 数值与字符串不会自动转换：想拼接数字和文本，需要用 TOSTR / TOINT；
  • 常见转换函数：TOSTR（数值→字符串）、TOINT（字符串→数值）、ISNUMERIC（判断能否转数值）。
#DimS Msg = "金币："
Msg = Msg + TOSTR(MONEY)

括号

拿不准优先级时，永远加括号。括号内的内容总会被最先计算：

A + B * 2    ; 先乘后加
(A + B) * 2  ; 先加后乘
