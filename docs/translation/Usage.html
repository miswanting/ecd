使用指南

翻译自原文档：https://osdn.net/projects/emuera/wiki/howto

运行环境

需要 .NET Framework 2.0 环境。

（注：当前版本的 Emuera 已可运行在更高版本的 .NET Framework 上。）

如果出现应用程序无法正常启动之类错误而无法启动，说明没有安装 .NET Framework 2.0。请从微软官网下载并安装 .NET Framework 2.0 运行时。

使用方法

把 EmueraXXX.exe 放在与 eramaker.exe 相同的文件夹中并启动。

（XXX 是表示版本的编号。另外，根据环境设置，.exe 可能不显示。）

如果无法启动，请阅读上面的运行环境一节。

启动后会立即生成 emuera.config，出错时会生成 emuera.log。

基本操作与 eramaker.exe 几乎相同，但可以用鼠标操作。

用鼠标对准选项（被 [] 包围的数字）并点击即可。

  • 用 Esc 键或右键可以跳到下一个选项；如果持续按住右键再选择选项，则选择后立刻跳到下一个选项；
  • 可以用 Ctrl+V 粘贴剪贴板内容；
  • 与 eramaker.exe 一样，按上下方向键可以调出之前的输入。

用 EraMakerEx 转换过的文件也可以直接运行。不过该功能默认关闭，需要时请在帮助→设置中勾选使用 _Rename.csv。

宏

Emuera 带有简单的宏功能。

例如输入 \e，就相当于按 Esc 键或右键，跳到下一个选项。

输入 \n 会分隔输入，进入下一次输入。例如输入 0\e\n1\e\n，就会输入 0 并跳到下一个选项，再输入 1 并跳到下一个选项。

此外，(～～)*n 会把括号内的输入重复 n 次。(0\e\n)*3 等同于 0\e\n0\e\n0\e\n。

宏执行过程中按 Esc 键可以中断。

把宏保存到功能键

创建的宏可以保存到 F1～F12 键上。

  • 按住 Shift 再按 F1～F12，即可把当前输入内容保存到对应的功能键；
  • 之后按 F1～F12 就能输入保存的宏；
  • 保存的宏会存放到 macro.txt。

（需要启用配置项使用键盘宏。）

此外，按住 Ctrl 再按数字键 0～9 可以切换宏分组。（启动 Emuera 时默认选择分组 0。）

分组 0 的 F1～F12 与分组 1 的 F1～F12 可以保存不同的宏，因此能保存更多宏。也可以在输入框上右键弹出的上下文菜单中切换分组。

直接编辑 macro.txt

也可以用文本编辑器直接编辑 macro.txt：

  • 在マクロキーF○:（宏键 F○）的冒号右侧，写入按下 F○ 时要输入的宏；
  • G×:マクロキーF○: 是选择分组 X 的宏；
  • 修改グループ×:マクログループ×に設定（分组 ×：设为宏分组 ×）右侧的消息，可以改变切换到分组 X 时显示的文本。

菜单

要使用菜单，配置中的使用菜单必须启用。默认启用。

文件

重启

重新启动 Emuera。

请注意，如果不保存，正在运行的游戏信息会丢失。

保存日志

把过去的日志保存到文件中。保存的最大行数与历史日志的行数相同。

返回标题画面

回到标题画面。

请注意，如果不保存，正在运行的游戏信息会丢失。

重新加载代码

在保留游戏信息的情况下重新读取 .erb 文件。

对于已经被调用过的函数，会执行之前的代码。旧代码会一直保留在内存中，直到被调用的函数结束，因此连续使用可能导致内存不足。

退出

退出 Emuera。
