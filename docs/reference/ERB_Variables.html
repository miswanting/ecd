ERB 的变量

变量是存放值的“有名字的容器”。本页按作用域和形态梳理 EraBasic 的变量体系，并附常用变量速查。完整的变量表请参阅常量与变量。

按作用域分类

作用域说明定义方式
私有变量只能在该函数内使用函数中 #DIM / #DIMS
局部变量LOCAL、LOCALS、ARG、ARGS，按函数区分内置，或 #LOCALSIZE 调整大小
广域变量所有函数共享ERH 中 #DIM / #DIMS
全局变量跨存档共享#DIM GLOBAL / SAVEGLOBAL

LOCAL、LOCALS 实际上是以 LOCAL@函数名 为名的公共静态变量，离开函数后值仍会保留——这一点和一般编程语言的局部变量不同。

按值的类型分类

类型说明定义前缀
数值型64 位整数#DIM
字符串型文本#DIMS

按形态分类

形态说明例子
非数组变量只有一个值A、MONEY
一维数组变量:下标FLAG:0、STR:10
多维数组变量:下标:下标[:下标]DA:0:1、TA:1:2:3
角色变量第一维是角色编号NAME:0、CFLAG:0:5
伪变量写成变量、实为函数RAND:100、CHARANUM

常用内置变量速查

流程与控制

变量说明
RESULT / RESULTS命令的数值 / 字符串结果
COUNTREPEAT 的计数器
MASTER主角的登录编号
TARGET当前目标的登录编号
ASSI助手的登录编号
CHARANUM当前角色总数
SELECTCOM当前选择的训练命令编号

显示与输入

变量说明
LINECOUNT当前已显示的行数

SAVEDATA_TEXT存档的标题文本

系统常量

变量说明
__INT_MAX__64 位有符号整数最大值
__INT_MIN__64 位有符号整数最小值
__FILE__ / __LINE__ / __FUNCTION__当前文件名 / 行号 / 函数名（调试用）

常用的角色变量

变量说明
NO角色的 CSV 编号
NAME / CALLNAME / NICKNAME名字 / 称呼 / 昵称
BASE / MAXBASE基础值 / 基础最大值
ABL / TALENT / EXP / MARK能力 / 素质 / 经验 / 刻印
CFLAG角色标志（自定义数据常用）
PALAM / STAIN / EX / JUEL参数 / 污渍 / 经验 / 珠
RELATION相性（对其他角色的关系）

CSV 派生的名称变量

这些变量保存了 CSV 中定义的名称，常用于显示或作为字符串索引：

变量对应 CSV
ABLNAME / TALENTNAME / EXPNAME / MARKNAMEAbl.csv / Talent.csv / Exp.csv / Mark.csv
PALAMNAME / STAINNAME / ITEMNAMEPalam.csv / Stain.csv / Item.csv
BASENAME / CFLAGNAME / STRNAME / TRAINNAME基础 / 标志 / 文本 / 训练

例如 ABLNAME:3 就是 Abl.csv 中编号 3 对应的名称。
