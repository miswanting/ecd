CSV 文件参考 ​

CSV/ 文件夹存放游戏的数据定义。Emuera 启动时会读取这里的文件，把角色、能力、物品等信息装进游戏。

  • 文件为纯文本，编码通常为 Shift-JIS；
  • 每一行用半角逗号分隔若干栏；
  • 以 ; 开头的行是注释，会被忽略；
  • 第一栏通常是编号，从 0 开始，一般不要留空号。

下面按文件分类列出常用格式。更详细的说明请参阅Eramaker 的 CSV 文件格式。

文件一览 ​

文件作用
GameBase.csv游戏的基本信息（代号、标题、作者等）
Str.csv全局文本（标题、按钮等固定用语）
CharaXX.csv角色定义（名字、基础、能力、素质等）
Palam.csv参数名称
Abl.csv能力名称
Talent.csv素质/天赋名称
Mark.csv刻印名称
Exp.csv经验名称
Train.csv训练/动作命令名称
Item.csv物品名称与价格
VariableSize.csv各数组变量的元素数
_replace.csv替换系统文本（货币单位、系统菜单等）
_rename.csv批量替换脚本中的文本

GameBase.csv ​

游戏的基本信息，一般只需一份。

字段含义
コード游戏代号（整数）
バージョン游戏版本
タイトル游戏标题
作者作者名
製作年制作年份
追加情報附加信息（启动时显示）
最初からいるキャラ初始角色（CSV 编号）
アイテムなし若为 1，则忽略训练中的物品
バージョン違い認める允许读取版本不同的存档

示例：

csv
コード,1
バージョン,1.00
タイトル,我的第一个游戏
作者,佚名
製作年,2026
追加情報,一个简单的示例。

Str.csv ​

用于注册全局固定文本（标题、按钮、系统提示等）。

字段含义
编号字符串编号（0～19999）
文本字符串内容

字符串里可以使用特殊占位符：

占位符含义
+++主角姓名
***被训练者姓名
$$$被训练者称呼
///助手姓名
===训练者姓名（主角或助手）

CharaXX.csv ​

定义角色。XX 是任意字符（如 Chara01.csv、CharaABC.csv）。一个角色可以分散在多个文件里定义，但同一编号的角色只会生效第一个。

字段含义
番号角色编号
名前名字（NAME）
呼び名称呼（CALLNAME）
基礎基础属性：基礎,<编号>,<值>
能力能力：能力,<编号>,<值>
素質素质：素質,<编号>
経験经验：経験,<编号>,<值>
相性相性：相性,<对象编号>,<值>
助手为 1 时初始即为助手
フラグ角色标志：フラグ,<编号>,<值>

示例：

csv
番号,1
名前,小明
呼び名,小明
基礎,0,2000
能力,0,10
素質,2

名称注册类（Abl / Exp / Talent / Mark / Palam） ​

这些文件的结构完全一致：第一栏编号，第二栏名称，用于给游戏里的一串数字起名字。

csv
0,感知
1,体力
3,技巧

对应的变量分别是 ABL、EXP、TALENT、MARK、PALAM。例如在 Abl.csv 里注册了 3,技巧 之后，脚本里就能写 ABL:技巧 或 PLAYER:3 来引用它。

Train.csv ​

字段含义
编号训练命令编号（0～99）
名称命令显示名称

示例：

csv
0,休息
1,锻炼

对应的变量是 TRAINNAME，脚本中可用 TRAINNAME:0 取得名称。

Item.csv ​

字段含义
编号物品编号（0～99）
名称物品名称
价格物品价格

示例：

csv
0,药水,150

对应的变量是 ITEMNAME、ITEMPRICE、ITEMSALES 等。

VariableSize.csv ​

用于修改各数组变量的元素数。格式为 变量名,元素数：

csv
ITEMNAME,1000
TALENT,500

未列出的变量使用默认大小。修改 ITEMNAME 的大小会对商店显示范围产生影响，详见关于 _replace.csv。
