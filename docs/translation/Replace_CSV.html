关于 _replace.csv ​

翻译自原文档：https://osdn.net/projects/emuera/wiki/replace

在 CSV/ 文件夹中放置一个名为 _replace.csv 的文件，就可以对显示相关的项目进行设置。

金钱单位 ​

お金の単位 用于设置附加在 PRINT_SHOPITEM 所显示的商品价格上的单位。

默认值是 $。也可以使用包含全角字符或多个字符的字符串。

单位位置 ​

単位の位置 用于设置 PRINT_SHOPITEM 所显示的商品价格中，单位位于数字之前还是之后。

有效值为前或後，默认值为後。

启动时的简略显示 ​

起動時簡略表示 用于设置当配置中关闭了加载时显示报告功能时，取而代之显示的字符串。

默认值是 Now Loading...。

出售的物品数量 ​

販売アイテム数 用于设置购买处理中，哪些数值表示商品（进而调用 @EVENTBUY），哪些数值表示用户选项（进而调用 @USERSHOP）。

在 Eramaker 通常的 SHOP 处理中，PRINT_SHOPITEM 会显示所有 ITEMSALES 非 0 的 ITEMNAME（0～999）。

另一方面，只有输入 0～99 时才会进行购买处理和 @EVENTBUY；输入其他数值时会调用 @USERSHOP。

Emuera 基本上重现了这一处理。

改变販売アイテム数会改变进行购买处理的物品范围。

例如，把販売アイテム数设为 1000 时，输入 0～999 会进行购买处理，输入负值或大于等于 1000 的值则会调用 @USERSHOP。

注意：输入 0～（販売アイテム数-1）之间的值时，无论购买是否成功，都不会调用 @USERSHOP。

例如，販売アイテム数为 1000 时，[200] - 保存或[300] - 读取会被视为试图购买第 200、300 号物品，因而不会调用 @USERSHOP。

如果你想增加（或减少）PRINT_SHOPITEM 中显示的物品数量，请修改 VariableSize.csv 中 ITEMNAME 和 ITEMSALES 数组的元素数量。

ITEMNAME 和 ITEMSALES 数组中元素数量较小的一方，就是 PRINT_SHOPITEM 显示的物品范围。

DRAWLINE 字符 ​

DRAWLINE文字 用于设置 DRAWLINE 指令绘制分隔线时使用的字符。

默认字符是 -。

BAR 字符 ​

BAR文字1 与 BAR文字2 用于设置 BAR 或 BARL 指令中使用的字符。

默认情况下 BAR文字1 是 *，BAR文字2 是 .。

此时会显示为 [****....] 这样的形式。

也可以指定全角字符或由多个字符组成的字符串，但需要考虑显示会错位的问题。

另外，如果指定数字，Emuera 会把 [88881111] 之类的文本视为可点击的按钮，从而产生不自然的动作。

系统菜单 ​

システムメニュー0、システムメニュー1 用于设置标题画面最初显示的两个选项的文字。

默认值分别是 最初からはじめる（从头开始）、ロードしてはじめる（读取存档），显示效果如下：

[0] 最初からはじめる
[1] ロードしてはじめる

如果定义 @SYSTEM_TITLE 来使用自定义标题画面，则这里指定的字符串不会被使用。

请在 @SYSTEM_TITLE 中实现显示处理。

COM_ABLE 的初始值 ​

COM_ABLE初期値 用于设置在 TRAIN 中找不到 @COM_ABLE{X} 时所采用的值。

默认值是 1，即没有定义对应的 @COM_ABLE 时，认为该 COM 可以执行。

如果把这个值设为 0，则没有定义 @COM_ABLE 时会认为该 COM 不可执行。

@COM_ABLE{X} 函数用于判断某个调教指令在当前状态下对当前目标是否可用。 返回 1 表示该指令可用并显示在指令菜单中；返回 0 表示不可用，不会显示该指令。

污渍的初始值 ​

汚れの初期値 用于设置 STAIN 被初始化时赋予的值。

用 / 分隔即可指定 STAIN:1 之后的值。

默认值是 0, 0, 2, 1, 8。

超时显示 ​

時間切れ表示 用于设置像 TINPUT 这样有时间限制的输入指令在超时时显示的字符串。

默认值是 時間切れ（已超时）。

EXPLV 的初始值 ​

EXPLVの初期値 用于设置 EXPLV 的初始值，即调教经验（EXP）每提升一个等级所需的数值。

用 / 分隔即可指定 EXPLV:1 之后的值。

默认值是 0, 1, 4, 20, 50, 200。

PALAMLV 的初始值 ​

PALAMLVの初期値 用于设置 PALAMLV 的初始值，即调教参数（PALAM）每提升一个等级所需的数值。

用 / 分隔即可指定 PALAMLV:1 之后的值。

默认值是 0, 100, 500, 3000, 10000, 30000, 60000, 100000, 150000, 250000。

PBAND 的初始值 ​

PBANDの初期値 用于设置 PBAND:0 的初始值。

默认值是 4。

RELATION 的初始值 ​

RELATIONの初期値 用于设置 CharaXX.csv 中未指定 RELATION 时该值的初始值。

默认值是 0。
