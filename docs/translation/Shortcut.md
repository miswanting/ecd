# 快捷键

> 翻译自原文档：https://osdn.net/projects/emuera/wiki/shortcut

在 Emuera 中，可以用快捷键完成一些操作。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + B` | 最小化 Emuera 窗口 |
| `Ctrl + C`、`Ctrl + Insert` | 打开剪贴板对话框。仅在**没有选中任何字符**时有效；选中了字符时则只是复制该字符 |
| `Ctrl + V`、`Shift + Insert` | 粘贴已复制的字符 |
| `Ctrl + D` | 打开调试窗口。仅在以[调试模式](Debug_Mode)启动时有效 |
| `Ctrl + R` | 更新调试窗口中的信息，焦点不会移动。仅在以[调试模式](Debug_Mode)启动时有效 |
| `Ctrl + 0`～`9` | 把宏分组切换为分组 0～9 |
| `Shift + F1`～`F12` | 把当前输入的字符串作为宏分配到 `F1`～`F12` |
| `F1`～`F12` | 调用分配到对应键的宏 |
| `Esc` | 宏执行中按下，可中断宏 |

> 关于宏的用法，请参阅[使用指南](Usage)中的`宏`一节。
